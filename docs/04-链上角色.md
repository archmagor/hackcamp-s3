# 04 链上角色（OddsGate）

> 动手部分截至现在：x402 V2 sponsored 的 CCD 与 EUDemo（PLT）付款已在 testnet 多笔实测（含负向用例）；卖方 Agent Registry #974 Active + CIS-8 跨链绑定；H2A 身份档（VRA/VAA/token/extension/授权头）代码完成待钱包 E2E。以下回答 OddsGate 的链上角色。

## 链上发生的是哪个动作？
- **结算**（核心）：x402 V2 sponsored —— EUDemo PLT 从买方 agentWallet 转商户，sponsor 补签并代付 CCD 手续费；即时模式按笔上链，挂账模式 flush 批量上链（memo = tab 清单哈希，P2）。手续费由治理定价、与金额无关（一笔 sponsored 简单转账 = 635 NRG = 4.188669 CCD）；卖 0.1 级商品若买方付 gas 则手续费达标价 ~41 倍，故 sponsored 是必须项，且 path-to-production 必须回答批量 / 结算周期 / 更高客单价（挂账 flush 即为此）。
- **身份锚定**：VRA（验证请求摘要上链，防事后伪造请求）+ VAA（验证通过的审计摘要上链，留公开可核存证）—— server 自付 CCD 的两笔链上操作。
- **问责**：Agent Registry CIS-8004 / CIS-8 —— agent 注册、状态（active/suspended/revoked）、跨链密钥绑定（Base Sepolia ERC-8004）、badge。
- 身份属性（边缘）：dob / 居住国原值不出钱包，链上只有承诺与证明的验证结果。
- 不在链上：赔率数据（静态 fixture）、四门判定逻辑（server 侧，但门①查 Registry 链上状态、门②回链复验审计记录）、`/sales` 账本（链下 JSONL，引用链上 tx hash）。
- 现状：结算已实测（EUDemo tx `2b040e71…`：payer 300→299、merchant 100→101、sponsor 代付 5.652936 CCD）；身份锚定代码完成待钱包 E2E；问责卖方 Agent #974 Active（token address `JyP9Xmt95AaqN2sWY1tUe`，owner=agentWallet=merchant；CIS-8 绑 Base Sepolia server agent 10325，pubkey keccak=`0xf486…13f3`），**但徽章当前 invalid**（链上 `agent_uri` 为空、未托管 Agent Card，`check_account_badges` 报 valid 0/invalid 1）；买方注册与撤销演示未做。

## 对应的理由？
**选理由 1：多方互不信任，需要一个中立的结算或托管方。** 买方 agent、卖方、facilitator/sponsor 三方互不信任 —— agent 后端可被绕过、facilitator 回包不可尽信（故 merchant 独立复核）、资金转移须由谁都改不了的链上结算强制，且 sponsored 让买方无需持 CCD。
**理由 3（公开可核的审计）适用于身份锚定与问责：** VRA/VAA 让"人类授权了什么、验证是否通过"可被任何第三方独立复验，不依赖 server 单方日志；Registry 状态让撤销跨 server 全局生效。
（理由 2 只覆盖结算通道本身，非本项目独有；理由 4 是外部约束，不是设计理由。）

## 去掉链上还剩什么？
剩：商品目录、赔率数据、client 三级预算 / 白名单 / 记账、四门判定逻辑 —— 都不需要链。
链上独有的三件：sponsored 资金转移的中立强制（买方不持 CCD）；VRA/VAA 的防伪造 + 公开可核审计；Registry 状态的全局撤销。

判定：按当前成果（结算已实测、身份锚定待 E2E），链上已是**结算的必需层 + 身份的审计层**。
升级为"身份也必需"：钱包 E2E 跑通委托证明复验（门②靠回链复验审计记录 + Registry 状态撤销生效），判定标准即验收条件那条失败用例。
spike 失败（Verify and Access 不支持审计记录第三方复验）：启用降级链（会话窗口授权 → H2A 每笔 + 一次性 token，已实现），或老实放弃差异化。

## 评委在哪里看到？
1. CCDExplorer（`https://ccdexplorer.io/testnet/transaction/<txHash>`）：结算 tx 显示为 **"Sponsored Account Transaction"** 并列出与 Sender 不同的 Sponsor 账户；另有 VRA/VAA 锚定 tx、Agent Registry #974 合约页（提交物硬条件）。
2. Demo 视频三个时刻特写：首次授权出组合证明（VRA/VAA 上链）/ 自主购买过四门 + sponsored 结算 / 一条门校验失败被拒（无链上动作、无资金变动）。
3. 脚本输出与 `/sales` 账本自带 explorer 链接 + tx hash。

当前实测证据（EUDemo tx `2b040e71…`、sponsor 代付 5.652936 CCD、卖方 #974 Active）为 testnet 真实数据，可直接作参赛证据；旧 spike 的 Sepolia / Basescan 部分不算。
